> **核心结论（先说）**
> 1. Day 1 的基线指标**错了两次**，真实基线是 Image AUROC **0.9426** / Pixel AUROC **0.9047**（不是 0.8445 / 0.8387）。详见 `docs/Day2_Errata.md`。

## 一、Day 1 评估问题排查结果

审计脚本：`src/audit_postprocess.py`｜日志：`results/logs/audit_postprocess.log`｜结构化结果：`results/metrics/day2_audit.json`

Day 1 报了四个数：raw Pixel 0.8387 / 官方 Pixel 0.5889 / 自算 Image 0.8445 / 官方 Image 0.8849。
逐项追查后发现，**这四个数来自两个互相独立的缺陷**，而不是一个"后处理差异"。

### 1.1 缺陷 A：模型输入没有做 ImageNet 归一化（严重）

anomalib 2.x 把预处理拆成两半，这是根因：

| 环节 | 代码位置 | 是否在 DataLoader 内 |
|---|---|---|
| `uint8 → [0,1]` | 数据集 `__getitem__` | ✅ |
| `Resize(256, bilinear, antialias)` | 由 `_update_augmentations` 注入数据集 | ✅ |
| **`Normalize(ImageNet)`** | **模型 `PreProcessor`（Lightning 回调）** | ❌ **只在 Trainer 循环中施加** |

Day 1 的 `infer_raw()` 直接 `for batch in dataloader` 然后 `model.model(batch.image)`，
**绕过了 PreProcessor 回调**，于是 resnet18 收到的是未归一化的 [0,1] 张量。

实测证据（同一张图、同一模型）：

| 检查项 | 数值 |
|---|---|
| fit 前 `dataset[0].image` | 840×840，min 0.0627，max 1.0000 |
| fit 后 DataLoader batch | **256×256，min 0.0578，max 1.0000**（已 resize、**未**归一化） |
| 显式重建管线 | 256×256，**min −1.8069，max 1.7143** |
| 两者最大绝对差 | **1.878**（量级完全不同） |
| 同一张图图像分数 | **77.68（batch 口径） vs 116.72（正确管线）** |
| 同一张图热力图最大差 | 39.15 |

### 1.2 缺陷 B：PostProcessor 不是"逐图 Min-Max"，而是全局仿射 + clamp

Day 1 的解释是错的。源码 `post_processing/post_processor.py::_normalize`：

```python
normalized = clip((preds - threshold) / (max - min) + 0.5, 0, 1)
```

三个统计量全部来自**验证集**，与批次无关：

| 统计量 | 值 |
|---|---|
| image_min / image_max / image_threshold | 17.118 / 65.500 / 65.500 |
| pixel_min / pixel_max / pixel_threshold | 7.469 / 65.500 / 65.500 |
| 归一化后阈值 | 0.5（= 1 − sensitivity） |

公式复现误差：图像 **2.6e-08**、像素 **0.0** —— 完全吻合，可确认机制。

真正的破坏来自 `clamp` 截断造成的**并列（ties）**：

| 现象 | 数值 |
|---|---|
| 图像分数唯一值 | 117 → **47** |
| 排序与原顺序一致比例 | **41.0%** |
| 像素值被压到 0 | **95.6%** |
| 像素值被顶到 1 | 0.07% |

### 1.3 两个缺陷恰好抵消，掩盖了问题

| Day 1 数值 | 真实成因 | 修正后真值 |
|---|---|---|
| 官方 Image 0.8849 | 输入归一化**对**，分数被 clamp 扭曲 | 原始分数 0.9426 |
| 自算 Image 0.8445 | 分数未截断**对**，输入未归一化 | 同上 0.9426 |
| 官方 Pixel 0.5889 | clamp 把 95.6% 像素压成 0 | 0.9047 |
| 自算 Pixel 0.8387 | 输入未归一化 | 0.9047 |

**修正幅度**：Image AUROC **+0.0985**，Pixel AUROC **+0.0660**，Pixel AP **+0.0517**。

复现校验：本报告的"未归一化"口径得到 Image 0.8442 / Pixel 0.8387，
与 Day 1 的 0.8445 / 0.8387 一致（3e-4 差异来自掩码缩放方式，见 `Day2_Errata.md` E4），
说明审计定位准确，不是又一次猜测。

### 1.4 统一的原始分数评估协议（本日起生效）

| 项 | 规定 |
|---|---|
| 分数 | **模型原始马氏距离**（`PadimModel` 输出，不经 PostProcessor） |
| 输入管线 | `uint8 → /255 → Resize(256,bilinear,antialias) → Normalize(ImageNet)` |
| 输入验证 | 必须断言张量 min<0（即确实归一化了） |
| 图像分数 | 热力图最大值 |
| 像素指标 | 全局池化；256 尺度用 **nearest** 掩码；840 尺度用**原始掩码** |
| 阈值 | 只来自验证集（46 张正常图），禁止用测试集 |
| 框架对照 | 保留 anomalib 官方 evaluator 结果，仅作对照，不用于结论 |

## 三、256 与 840 双尺度评估

任务要求把分数图上采样到原分辨率再与原始 GT 比较。做法：
- 分数图：`F.interpolate(bilinear, align_corners=False)` → 840×840（连续插值）
- GT 掩码：**原始 PNG，零插值**，保持二值
- 不改变任何排序，只是把同一函数在更细网格上采样

| 条件 | Pixel AUROC @256 | Pixel AUROC @840 | 差 |
|---|---|---|---|
| original | 0.9047 | 0.9048 | +0.0001 |
| brightness_low | 0.9020 | 0.9022 | +0.0002 |
| brightness_high | 0.9027 | 0.9028 | +0.0001 |
| gamma_low | 0.9046 | 0.9047 | +0.0001 |
| gamma_high | 0.9032 | 0.9034 | +0.0002 |
| local_shadow | 0.9025 | 0.9027 | +0.0002 |

**结论：两尺度差异 ≤0.0002，可忽略。** 这直接**否定了 Day 1 的一个猜测**
（"在 840 复算会把 Pixel AUROC 拉到 0.9 以上"）——当时 0.8387 的瓶颈是归一化，不是分辨率。

同时必须说明：**上采样不恢复信息**。256 的 64×64 特征网格 + σ=4 高斯模糊决定了
定位精度上限，840 评估只是把同样的模糊函数采样得更细，不会凭空产生细节。
Pixel AP 在 840 上略高（0.3279→0.3282），属于插值带来的极微小效应，不构成"改进"。

后续主实验统一使用 **256 评估**（模型原生尺度、与文献可比），840 作为稳健性附报。

## 四、光照扰动定义

实现：`src/perturbations.py`。作用于 **840×840 原始 8-bit sRGB 图像**，在 Resize 之前。

| 条件 | 数学定义 | 参数 | 平均亮度变化 |
|---|---|---|---|
| original | y = x | — | 0.000 |
| brightness_low | y = clip(0.8·x, 0, 1) | k=0.8 | −0.087 |
| brightness_high | y = clip(1.2·x, 0, 1) | k=1.2 | +0.087 |
| gamma_low | y = x^0.7 | γ=0.7（提亮中间调） | +0.118 |
| gamma_high | y = x^1.4 | γ=1.4（压暗中间调） | −0.116 |
| local_shadow | y = x·L(p) | A=0.50, σ=0.30H, c=(0.35H, 0.40W) | −0.094 |

局部阴影的光照场：`L(p) = 1 − 0.50·exp(−‖p−c‖²/(2σ²))`，范围 [0.50, 1.00]，
**平滑高斯衰减、全图统一位置、与图像内容无关**，不是叠加黑色矩形。

关于信息损失（像素截断，逐图统计后取极值）：

| 条件 | 最大欠曝比例（像素=0） | 最大过曝比例（像素=255） |
|---|---|---|
| brightness_high | 0.00% | **3.35%**（最亮的一张图） |
| 其余条件 | 0.00% | ≤0.01% |

即扰动整体温和，只有 brightness_high 在少数亮图上造成轻微不可逆过曝。

**声明**：这是**合成光照压力测试**，不等于真实工业照明鲁棒性验证。

### 5.1 必须同时报告的"反向"结果

不能只挑恶化：**局部阴影与 Gamma 1.4 让 Pixel AP 上升，Gamma 0.7 让 AUPRO 上升，
局部阴影让召回率从 0.583 升到 0.619（多救回 4 张漏检）**。
这些都属于"阈值附近重排"，不是方法变好——但报告里必须同时列出，否则是选择性呈现。

### 5.2 一个必须提前说明的协议弱点

阈值 55.48 落在**正常分数分布内部**（33 张正常图的最高分是 64.60），
所以基线的 3.03% 误报率就是"1/33 越界"。这意味着：

- **"误报率不变"是结构性结果，不是模型稳健的有力证据**。唯一的误报图
  `good/020.png`（Original 64.6）在 5 种条件下的分数是 59.6 / 68.7 / 60.7 / 64.3 / 64.1，
  **全部仍高于 55.48**，所以它一直是误报；其他 32 张正常图离阈值都很远
  （箱线图可见主体在 20~45，阈值 55.5），因此不可能新增误报。
- 84 张缺陷中只有 **7 张**落在阈值 ±5 的区间内，所以标签翻转数量天然很小。

因此本节结论以**阈值无关指标（AUROC/AP/AUPRO）为主**，阈值指标只作辅助参考。
若要真正检验"光照是否诱发误报"，阈值必须下移到正常分布内部（如 val p99≈64），
让正常图有机会越界——这是下一步必须做的实验（见 §8.1）。

## 六、失效案例分析

图：`figures/day2_illumination/`（11 张）｜数据：`results/metrics/day2_analysis.json`

### 6.1 正常样本（33 张）：PaDiM 是否把光照当成异常？

分数位移（相对 Original，逐图配对后取均值）：

| 条件 | 正常 Δmean | 上升/下降张数 | 新增误报 |
|---|---|---|---|
| Brightness 0.8 | −0.35 | 15 / 18 | **0** |
| Brightness 1.2 | +0.25 | 16 / 17 | **0** |
| Gamma 0.7 | +0.56 | 18 / 15 | **0** |
| Gamma 1.4 | −0.16 | 14 / 19 | **0** |
| Local shadow | +0.04 | 17 / 16 | **0** |

**回答：几乎不会。** 5 种条件、33 张正常图，**没有任何一张被光照从"正确"推成"误报"**。
但要说清这个结论的边界：唯一在阈值之上的 `good/020.png` 本来就是误报，
它在 5 种条件下始终高于阈值；其余 32 张正常图距离阈值有 10 分以上的余量，
本来就不可能越界。所以准确表述是：**光照把正常分数整体抬升了最多约 1 分（均值级别）
和 6.6 分（单图极值），但不足以让"原本正确的正常图"越过当前阈值。**
若阈值更靠近正常分布上缘，结论可能不同——这正是 §8.1 要补的实验。
最大单图升幅出现在 Gamma 0.7 的 `good/023.png`（+6.6）与 Local shadow 的 `good/016.png`（+6.3），
方向与亮度变化一致（提亮 → 分数升），但幅度远小于到阈值的距离。

对应可视化：`fig05_heatmap_normal_1/2/3_*.png`（选取标准预先声明为"扰动后分数升幅最大"，
不是事后挑图）。热力图显示正常图的响应热点在提亮后**略微变亮但不改变位置**。

## 七、最小化研究结论（逐条回答任务 4 的六问）

### Q1 光照变化是否确实降低了 PaDiM 的检测性能？

**是，但幅度很小，且高度依赖指标。**

- 5/5 条件的 Image AUROC 都低于 Original（−0.0014 ~ −0.0177），方向一致；
- Pixel AUROC 全部微降（−0.0001 ~ −0.0027），几乎可忽略；
- 但 Pixel AP 有两项**上升**（Gamma1.4 +0.0036、Local shadow +0.0033），AUPRO 有一项上升。

由于本管线位级可复现，这些差异**不是随机噪声**，是真实的系统性小偏移。
但"小"到什么程度：Image AUROC 从 0.9426 掉到 0.9250，相对降幅 1.9%。

### Q2 哪一种光照变化影响最大？

- **Image 级：Gamma 0.7（提亮中间调）最不利**，−0.0177；其次 Local shadow −0.0115、Brightness 0.8 −0.0108。
- **Pixel 级：Brightness 0.8 最不利**（−0.0027），但差异在 0.001 量级。
- **缺陷区响应：Local shadow 削弱最明显**（−1.129）。

即"最不利"取决于看哪个指标——这本身说明效应不集中在单一维度。

### Q3 主要问题是正常误报增加，还是缺陷漏检增加？

**都不是。** 这是本日最清楚的一条结论：

- **新增误报 = 0**（5 个条件，33 张正常图，无一越界）；
- 漏检净变化最大为 +1（Gamma 0.7：新增 3 张漏检，同时救回 2 张）。

⚠️ 但"新增误报 = 0"要打折看：见 §5.2，当前阈值下 32/33 的正常图距离阈值有 10 分以上余量，
结构上就很难新增误报。**这条结论的强度取决于阈值位置，而非模型鲁棒性本身。**
更可靠的表述是：在本阈值下，光照引起的分数上移（正常图均值级 ≤0.6 分、单图 ≤6.6 分）
不足以改变正常图判定；而缺陷图因分布在阈值附近（7 张在 ±5 内），会出现双向抖动。

真实效应形态是"**分数整体轻微漂移 + 阈值附近双向抖动**"，不是误报潮或漏检潮。

### Q4 影响发生在图像级判别还是像素级定位？

**主要在图像级判别，像素级定位基本不受影响。**

| 维度 | 相对变化幅度 |
|---|---|
| Image AUROC | 最大 −1.9%（0.9426→0.9250） |
| Pixel AUROC | 最大 −0.3%（0.9047→0.9020） |
| AUPRO | −0.9% ~ +0.9%（有升有降） |

图像级变化是像素级的 4~10 倍。结合热力图可见：**热点的位置和形状几乎不变，只是强度变了**。
含义：光照影响的是"整体异常分数标定"，不是"缺陷在哪里"。

### Q5 有没有证据表明局部光照比全局亮度变化更难处理？

**部分有，但不能说"整体更难"。**

- 支持的一面：局部阴影使**缺陷区响应降 1.129**，是其他条件的 1.5~3 倍；
  且它使正常图分数几乎不动（+0.04）——即它专门削弱真实缺陷，而不抬高正常图，方向性最"坏"。
- 不支持的一面：Image AUROC 上它（−0.0115）并不比 Gamma 0.7（−0.0177）或 Brightness 0.8（−0.0108）更差；
  召回率甚至从 0.583 升到 0.619。

结论：**"局部阴影专门削弱真实缺陷响应"有初步证据；"局部光照整体更难"证据不足。**

### Q6 当前实验是否支持继续研究"光照条件下的异常分数校准"？

**有条件支持。**

支持的理由：
1. 误差形态恰好是"分数漂移"而不是"定位错误"——这正是校准能修正的形态；
2. 局部阴影对缺陷响应的削弱（−1.13）与正常图几乎不动（+0.04）说明存在可分离的结构；
3. 基线本身不完美（Pixel AP 0.328、召回 0.583），有明确的改进空间。

不支持/需警惕的理由：
1. **效应量太小**。Image AUROC 只掉 1.9%，任何"校准模块"的增益都会落在这个量级，
   很难与实现细节的波动区分（虽然本管线已可复现，但换骨干/换类别后不一定）；
2. **只有 6 个单点条件**，没有找到"失效拐点"。单点扰动下的 1% 差异很难撑起一篇 Q3/Q4 的贡献；
3. **合成扰动 ≠ 真实照明**，外部效度不足。

## 八、下一步建议

### 8.1 必须优先做（决定方向是否成立）

1. **找失效拐点，而不是继续加单点条件**。
   把扰动强度做成梯度并扫描：亮度 k ∈ {0.8,0.6,0.5,0.4,0.3}、γ ∈ {0.7,0.5,0.4,0.3}、
   阴影 A ∈ {0.5,0.65,0.8}，画出 **Image AUROC vs 强度曲线**，定位 PaDiM 的 breakdown point。
   如果曲线在物理合理范围内是平的，说明这条路走不通，应及时止损——这比再跑 10 个单点条件有价值得多。
2. **换阈值协议**。当前阈值（val `mean+3σ`=55.48）落在正常分数分布内部（正常最高 64.60），
   使 FPR 指标失真。改为 val 分位数（p95/p99）并给出 FPR–Recall 敏感性曲线，
   阈值相关结论才有意义。
3. **在第二个类别上复核**。只跑 tile 一类，无法区分"PaDiM 稳健"与"tile 这个类别的裂纹
   本来就对光照不敏感"。建议加 `carpet` 或 `leather`（同为纹理类，成本低）。
   注意：这属于扩类，不是 MVTec AD 2。

### 8.2 与课题主线的衔接

4. **把研究问题从"光照是否降低性能"改写为"光照是否破坏分数标定"**。
   本日证据（定位不变、强度变、正常图不动、缺陷响应降）支持这个更精确的表述，
   也更容易做出方法贡献（标定/校准），且不需要改 PaDiM 主干。
5. **区分"全局光度漂移"与"空间光照不均"两条线**。前者可用单调校准处理，
   后者涉及空间非平稳性，是更有意思但更难的问题。本日数据显示二者机制不同
   （前者改整体分数，后者专门压缺陷响应）。
6. **补真实数据**。合成扰动只能证明"对这类扰动不敏感"，无法支撑"工业照明鲁棒"的论断。
   下一步应考虑受控光照下的实拍 tile 图（哪怕几十张），否则审稿人一定会质疑外部效度。
